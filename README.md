# 一件 · 我的待办

Windows 蓝主题的待办应用，卡片为半透明液态玻璃质感，也可以上传自己的照片作为磨砂背景。打开后默认进入「计划日历」，按截止日期在扁平月历上查看待办；左侧还可切换到「待办清单」「艾宾浩斯」和「专注钟」：前者以瀑布流展示待办（卡片大小随机、错落排列），右侧按单列展示除长期事项外的置顶待办；艾宾浩斯用遗忘曲线安排已完成待办的 1／3／7／15 天复习；专注钟提供可自定义时长的全屏专注计时。待办标题与正文支持 Markdown；每条待办还可以附加 DOCX／PDF／PPT 文档及常用图片，图片会在详情中直接预览。

## 启动

双击 `启动待办.cmd`，会自动打开 http://127.0.0.1:4173 。使用期间保持命令窗口打开。重复启动会打开已有服务。需要 Node.js 20 或更高版本，无需安装依赖。

也可以在本目录运行 `node server.mjs`。

直接打开 `index.html` 可以使用浏览器存储和分组功能；保存到电脑文件夹需要通过本地服务打开。

如果已在 HTML 文件页面添加了待办，启动服务后，请在原 HTML 页面刷新并点击提示中的「打开本地保存页面（携带当前待办）」。它会将分组、标题、正文和置顶状态带入本地页面，合并已有内容；相同 ID 的待办使用携带的版本。然后点击「本地保存」。文件页面和本地网址的浏览器缓存彼此独立。

## 使用

- 左侧「工作空间」可在「待办清单」「计划日历」「艾宾浩斯」与「专注钟」之间切换。打开网页或刷新时默认进入计划日历，不会自动弹出每日任务。原「全部待办」顶部的「作业」「长期事项」大卡片已移除，两个特殊分组仍保留在左侧，可点击进入或拖入待办。
- 新建或编辑待办时可勾选「作业」「长期事项」，两个选项可以同时勾选，并与原有普通分组共存。特殊分组页面中新建时默认勾选当前类别；可在编辑窗口取消所属特殊分组。
- 长期事项不出现在「全部待办」及右侧「置顶待办」中，仍可从「长期事项」、原有普通分组或「未分组」查看；若属于作业，也会出现在「作业」中。紧迫时仍参与「要紧的事」轮播。取消长期标记后恢复显示，原置顶状态保留。
- 两个特殊分组仅记录任务标记，不创建文件夹，不改变文件位置。文件仍按原普通分组保存，未分组的文件仍保存在根目录。
- 点击左侧「我的分组」旁的 **+** 新建分组。名称直接作为磁盘文件夹名，不能包含 Windows 不允许的字符或系统保留名称。
- 把待办卡片拖入左侧分组即可移动；也可以使用每张卡片底部的「移动到」菜单。拖到「未分组」可移回根目录。
- 点击任意待办卡片（按钮、下拉菜单或正在框选文字时除外）会以卡片为起点播放类似手机 App 的容器形变动画，展开为更大、更舒展的居中磨砂详情浮层，并保留完整标题、正文换行、分组、优先级、特殊标记、截止与创建时间。浮层保留半透明高斯模糊毛玻璃质感，尺寸受控、正文内部滚动，不会铺满屏幕；页面背景不再压暗，而是用更强的高斯模糊把浮层与背景区分开。正文可直接框选复制，也可点击「复制内容」写入剪贴板。按 Esc、点右上角关闭或点击遮罩会回缩到原卡片；折叠、编辑、完成、置顶、删除与「移动到」菜单仍保持原行为。系统开启减少动态效果时直接显示，不播放形变动画。
- 「待办事项」工具栏和「已完成」汇总页标题旁提供一键「全部折叠／全部展开」按钮：按当前页全部可见卡片（待办、已完成、置顶与紧迫卡片）统一切换；只要还有展开的卡片就显示「全部折叠」，全部收起后变为「全部展开」。按钮会随单卡折叠实时更新，状态与单卡折叠一致写入浏览器保存并计入「折叠卡片／展开卡片」待保存差异，刷新后保留。
- 点击分组，只查看这个分组的待办。在分组内新增的待办自动归入当前分组；在「全部待办」内添加则归入「未分组」。
- 点击图钉置顶或取消置顶。右侧显示所有分组的置顶事项，每行一张正方形卡片，切换分组不影响；桌面端置顶栏随页面滚动保持可见，内容较多时可单独滚动。
- 点击垃圾桶删除待办。浏览器自动保存每次更改；点击右上角 **本地保存** 或按 **Ctrl+S** 写入电脑。
- 点击每张卡片编辑／删除等操作栏**上方**那枚加大、主题蓝磨砂的圆角矩形 **√** 按钮标记完成（完成后变为实心蓝，并将图标换成撤回箭头）。完成的事会从待办区移除：主页（全部待办）不再显示已完成区域，保持首页清爽；进入某个普通分组时，该分组底部仍有「已完成」区域；左侧「已完成」分组汇总所有完成的事。原普通分组、作业／长期标记、置顶状态和本地文件位置都保持不变。再次点击这个撤回按钮可取消完成，事项回到原分组。已完成的事不参与右侧「置顶待办」和「要紧的事」轮播，完成状态会随浏览器自动保存和本地保存写入待办文件。已完成卡片保持可展开：展开时卡片按内容自适应高度，正文、完成／撤回操作行与底部「移动到」分组菜单都整齐收在卡片圆角内，不再溢出卡片边缘；折叠后正文收成一行预览并隐藏分组菜单。
- 顶栏显示「有待保存的更改」时，表示浏览器中的内容尚未写入本地文件。将鼠标移到文字上（或用 Tab 聚焦）会列出与上次本地保存相比的具体变更，包括新增、删除、修改、完成、移动、置顶、分组调整和每日任务；修改事项时会列出变化的字段。保存成功后恢复为「已保存到本地」，之后的更改只显示新的差异。新增后又删除、完成后再取消等最终回到原状的操作不会残留待保存提示。
- 标题和正文可以分别填写，也可只填写其中一项。未单独填写标题时，正文开头的 `**…**` 会被识别为标题，可用 `**标题** 正文` 或 `**标题` 后换行输入正文；已单独填写标题时，正文完整保留并按 Markdown 渲染。
- 标题和正文支持 Markdown：标题、无序／有序列表、任务清单、加粗、斜体、删除线、行内代码、代码块、引用、分隔线和链接。原始 HTML 会被转义，不会执行脚本；链接只允许 `http(s)` 和 `mailto`。Markdown 图片语法会作为安全链接展示而不加载外部图片，图片请通过附件添加。详情浮层的「复制内容」复制的是原始 Markdown 文本，便于保留格式。
- 点击铅笔编辑待办，在窗口内修改标题、正文并保存；取消或按 Esc 放弃修改。正文支持换行，Ctrl+Enter 保存修改。添加区域按 Enter 添加，Shift+Enter 换行。
- 每个待办支持附件：点击卡片操作栏的回形针按钮，或展开详情浮层后点击「添加附件」，可选择 **DOCX、PDF、PPT / PPTX** 以及 **PNG、JPG/JPEG、GIF、WebP、BMP、AVIF** 图片；单个文件不超过 20MB，每个待办最多 8 个附件。卡片元数据区显示回形针和附件数量；详情浮层会把图片直接显示为内嵌预览，文档则以文件行列出，均提供「下载」和「移除」。附件元数据随待办保存，实际文件保存在本地保存目录的 `.attachments/<待办ID>/` 文件夹中；添加或移除附件会进入「有待保存的更改」，点击本地保存后写入或清理对应文件。附件功能需要本地保存服务，直接打开 HTML 文件或服务未启动时只能查看待办、不能上传或下载附件。
- 主列表中的未完成卡片会根据截止日期自动切换三档玻璃渐变色：无截止日期或 8 天以上使用最浅档，4–7 天使用中档，3 天以内（含逾期）使用最深档；紧迫待办使用紫色主题，一般待办使用蓝色主题。跨日进入下一档时卡片颜色会在后台刷新，已完成卡片保持绿色，置顶与要紧侧栏卡片保持各自独立的配色。
- 「待办事项」区为瀑布流：每张卡片的高度按待办随机分配（同一待办每次打开保持一致），紧迫待办排在一般优先级之前。展开的卡片会按屏幕宽度保留足够的最低高度，随机高矮不会把标题、正文或底部「移动到」菜单挤出卡片。向下滚动、卡片从画面底部进入视野时，从高斯模糊逐渐变清晰并轻微放大展开；每次卡片完全离开画面下方、再次从底部进入时都会重新播放模糊展开；首屏卡片和向上滚动从顶部进入的卡片直接清晰显示，不做模糊动画；重渲染不会让当前可见的卡片重新模糊。系统开启减少动态效果时直接清晰显示。
- 点击卡片右上角箭头折叠或展开。折叠后显示标题（没有标题时显示正文首行），下方保留一行正文预览，长内容会横向循环滚动，多行正文合并在一行展示；短内容静止显示，鼠标悬停或键盘聚焦时暂停滚动。只有标题时不显示空白正文行。展开后恢复该待办原有的随机高度。中间、右侧置顶与要紧的事同步更新，折叠状态会保存在浏览器及本地文件中。系统开启减少动态效果时改为手动横向滚动阅读。
- 创建或编辑时可以选择截止日期与「一般／紧迫」优先级，默认一般，日期可留空。截止时间按浏览器当地时区当天 23:59:59 计算，剩余严格不足 72 小时或已经逾期，自动按紫色「紧迫」显示；手动设为紧迫的事项一直保持紧迫。延期到 72 小时以外后恢复手动选择的优先级。
- 「计划日历」参考扁平月历风格：以周一开始的 42 格月历展示，日期之间不用格子线分隔，数字加粗加大，周末数字用红色呼应传统日历。日期数字整体置于一个纯色形状中：今天为蓝色、有待办截止为紫色，今天同时有截止时按蓝色显示；仅有已完成事项的日期不填充。该纯色形状带比面板更重的毛玻璃效果以作区分。工具栏提供「圆形／圆角」开关，可自由切换数字与选中高亮的形状（默认圆形），选择会记住并在刷新后保留；旁边的「大小」滑杆可在 70%–150% 间实时缩放数字形状与字号，行高随之自适应，同样记住并在刷新后保留，窄屏下自动收敛到合适基准尺寸。整个日历与下方议程都覆盖强毛玻璃效果，透出背景光晕或自定义照片。可切换上／下月或回到「今天」；鼠标悬停或键盘聚焦日期数字，可查看当天全部任务的标题、正文、分组与紧迫信息。点选日期后，下方议程列出当天截止待办，点击任务可直接编辑。日历直接读取待办的截止日期，不会复制保存；修改、完成或改期后，填充色与悬停详情立即同步。移动端缩小数字与形状，仍可点选查看议程。
- 「艾宾浩斯」工作区用遗忘曲线安排已完成待办的记忆复习：待办完成后自动进入记忆周期，参与记忆的任务按已完成天数落在曲线上（横轴为完成后的天数，纵轴为记忆保持率），曲线上标出 1／3／7／15 天复习节点，今日应复习的任务以紫色高亮；若仍有逾期未打卡的任务，横轴会按最晚天数自动延长。曲线上的任务标签使用应用中文字体并带描边光晕，自动避让任务圆点和彼此，避免小字与路径互相压叠。切换到艾宾浩斯工作区时，曲线从左到右描绘、面积渐显、任务点按完成天数依次弹出；系统开启减少动态效果时直接显示完整曲线。右侧「今日应记忆」只列出当天有未打卡复习节点的已完成待办，按完成时间从早到晚排列。每张卡片有「1天」「3天」「7天」「15天」四个打卡按钮：已到期的按钮可点击、已完成显示对勾、未到期禁用；当天打卡完成后，该待办会在下一次复习日再次出现，4 次全部完成后自动移出列表并退出曲线。取消完成会清空打卡并退出记忆周期。卡片同时展示分组、已完成天数、复习进度和今日应打卡节点，顶部统计参与记忆、今日待复习和完成周期。复习状态随浏览器自动保存和本地保存写入待办文件。
- 「专注钟」工作区可设定 1–180 分钟的专注时长，提供 15／25／45／60 分钟快捷选项和自定义输入，最后一次时长会记住。还可以从所有未完成待办中选择一件作为本次专注目标（已完成待办不会进入列表，选择会被记住）；设置区显示分组、截止日期和正文摘要，进入专注后全屏界面完整展示所选待办的标题与正文，长内容可在待办卡片内滚动阅读。开始后会进入深色或浅色主题对应的全屏专注界面：显示大号倒计时、进度环和「只做这一件事」提示，并尽量通过浏览器全屏、Keyboard Lock、页面遮罩、防误关提示和屏幕唤醒锁减少干扰。按 Win+Esc、或按住 Esc 3 秒、或按住「结束专注」按钮 3 秒可结束；专注完成后自动退出全屏并显示本次结果。由于网页无法阻止 Windows 系统级快捷键（Win 键、Alt+Tab、Ctrl+Alt+Del 等），也无法真正锁定电脑，这里的「锁定」是浏览器内的全屏专注模式，并在界面上明确提示真实边界。
- 右侧「要紧的事」位于置顶区上方，汇总所有分组的紧迫待办，每次显示一张，每 3 秒以非线性缓动（先加速后减速）横向向左滑动切换：旧卡片滑出、新卡片同时滑入；手动查看上一件时向右滑动。可手动前后切换或暂停；鼠标停留、键盘焦点在轮播中、编辑窗口打开或拖拽时暂缓自动切换。只有一件时保持显示，没有时显示空状态。系统开启减少动态效果时直接切换不做滑动。
- 顶栏的日历图标打开每日任务，支持新增、直接修改文字、删除和勾选完成。清单只需填写一次，保存后每天沿用，想调整时再编辑；打开页面后点击按钮查看，不再自动弹窗。只有完成勾选按浏览器当地日期重置，清单内容始终保留。更改自动存入浏览器；弹窗内点击「保存每日任务」可将当前工作空间（包括每日清单）写入本地索引，右上角「本地保存」也可保存。直接打开 HTML 文件时，「保存每日任务」保存到当前浏览器；迁移到本地服务时也会携带每日任务。
- 顶栏的月亮／太阳按钮切换深色与浅色模式。未手动选择时跟随系统外观；手动切换后记住选择，刷新、新标签页和直接打开 HTML 文件都保持。深色模式下卡片、弹窗、每日任务、紧迫区、计划日历与日历悬停详情均有对应配色，日期选择器和滚动条也使用深色原生样式。主题只存在浏览器中，不写入待办文件。
- 顶栏的图片按钮可以上传自己的照片作为工作空间背景。图片会自动压缩并保存在当前浏览器，显示时默认叠加一层高斯模糊和随主题变化的柔光遮罩；卡片另有独立的磨砂与透明度滑杆，可按需调节。背景弹窗内提供三组独立滑杆：「背景磨砂强度」可在 0–40 px 间实时调节照片的朦胧程度；「卡片磨砂强度」可在 0–80 px 间独立控制卡片的高斯模糊，默认 26 px，0 表示完全清晰；「卡片透明度」默认 38%，可在 0–80% 间调节卡片玻璃底的通透程度，0% 更实、80% 更透，文字和图标始终保持清晰。卡片磨砂与透明度都不随背景磨砂自动变化，三组设置都会记住并在刷新后保留；升级时如果已有背景或旧的增强磨砂设置，会按原来的有效值初始化卡片磨砂，避免观感突变。可随时更换或移除背景；移除背景只影响背景，卡片磨砂与透明度保持滑杆设置。背景、背景磨砂强度、卡片磨砂和卡片透明度设置都不会写入待办文件，也不会随「打开本地保存页面」迁移，清除浏览器数据后会回到默认设置。
- 所有待办卡片（待办、置顶、要紧的事、已完成和空状态）使用液态玻璃效果：半透明底色叠加背景高斯模糊、饱和提升与高光描边；每张卡片在主题色内叠加上浅下深的同色系渐变，左上呈受光面、右下明显更深更饱和，形成轻微透光玻璃或发光屏幕感，同时不增加明显包边、倒角或立体阴影；已完成卡片额外带一层绿色玻璃光泽并独立合成，确保滚动到已完成区域时磨砂依然生效、透出被柔化的照片。默认为缓慢漂移的蓝、紫、青、暖橙光晕背景，上传照片后则透出被柔化的照片。计划日历采用扁平化月历与纯色日期格，不叠加液态玻璃。深色模式使用对应的深色玻璃与日历配色，弹窗背后的页面也会模糊。系统开启减少动态效果时光晕停止漂移。

## 过渡动画

页面载入、切换分组、切换待办／日历／艾宾浩斯／专注钟工作空间、日历翻月和切换深浅主题时，只在中间主工作区使用毛玻璃过渡，侧边栏与顶栏保持清晰。模糊由 14px 按非线性曲线逐渐减弱，持续 1.2 秒；工作区当前可见的卡片、按钮、文字及表单控件按实际位置从上到下分批上浮淡入，同一行同步出现，整套入场在 1.2 秒内完成。刷新时侧栏、顶栏和图标保持静止；工作区只使用一套无超调的入场动画，避免重复动画造成弹跳。屏幕外卡片继续沿用滚动入场效果。过渡不阻塞点击，连续切换只保留最新一次动画，重复选中当前分组不重播；新增、折叠等局部更新不会触发整区模糊。

鼠标悬停时，待办卡片放大约 2.2%，普通按钮放大约 5.5%，侧栏导航放大约 2.5%；缩放采用带回弹的非线性曲线，移开后回弹恢复，按压时轻微缩小。缩放独立于瀑布流、拖拽与紧迫轮播的位置动画，日历议程也有同样的反馈。触屏设备不触发悬停放大；系统开启「减少动态效果」时关闭毛玻璃过渡与缩放回弹。弹窗、提示条、卡片落位和滚动进入视野的局部动效继续沿用已有表现。

## 本地保存

默认使用系统「文档」目录下的 `Todo` 文件夹。本机通常是 `C:\Users\Harmo\Documents\Todo`；若系统文档目录已迁移到 OneDrive，则使用系统配置的位置。

```text
Documents/Todo/
  .todo-workspace.json       # 恢复用的完整索引，包含分组及置顶状态
  <待办ID>.todo.json          # 未分组待办
  .attachments/               # 待办附件的实际文件
    <待办ID>/
      <附件ID>.<扩展名>
  工作/
    <待办ID>.todo.json        # 「工作」分组待办
  学习/
    <待办ID>.todo.json        # 「学习」分组待办
```

保存会创建空分组文件夹；移动和删除后再次保存，会清理应用之前创建的旧待办文件以及不再被引用的附件文件。不会删除用户自己放入的文件或递归删除目录。附件上传与下载以及新的 Markdown 渲染脚本由本地服务提供；如果页面已经打开但运行的是旧版本服务，请关闭服务窗口并重新运行「启动待办.cmd」，附件与 Markdown 功能才会完整生效。

重新启动时读取本地索引，结合浏览器缓存恢复较新的版本。原版本 `yijian.todos.v1` 的浏览器待办会自动迁移为未分组事项。请通过相同浏览器、相同网址打开以迁移旧缓存。

待办 JSON 可供查看和备份，应用恢复以 `.todo-workspace.json` 为准；直接修改单个待办文件不会自动导入。不同页面同时保存时，旧页面会收到版本冲突提示，防止静默覆盖。

默认仅绑定本机 `127.0.0.1`。可用环境变量 `TODO_DATA_DIR` 修改保存路径、`TODO_PORT` 修改端口。打开页面时不会新建磁盘目录；点击本地保存或添加附件时才会写入。添加附件会先写入 `.attachments` 文件，点击本地保存后把附件信息写入待办文件。
